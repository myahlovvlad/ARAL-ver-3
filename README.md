# ARAL

Статический многостраничный сайт. Релизная сборка использует R12. Адрес GitHub Pages — https://myahlovvlad.github.io/ARAL-ver-3/.

## Сборка и локальный просмотр

Из корня проекта запустите:

```sh
python scripts/build_site.py
python scripts/validate_catalog.py _site
python -m http.server 8000 --directory _site
```

Сайт откроется по адресу `http://localhost:8000/`. Для сборки нужна пустая директория. Новый путь можно передать как `--output <путь>`.

Скрипт `scripts/build_site.py` собирает семь документов R12, их ресурсы, публичный `catalog.json` и три локальных PDS с проверкой SHA-256. Сборка выполняется без загрузки файлов из сети. Существующие ссылки каталога на Google Drive остаются внешними. Доступ к этим документам определяется правами в Drive.

В релизе корневой адрес открывает главную R12. Старые адреса из опубликованного комплекта перенаправляются на соответствующие страницы R12. Закладки на «О бренде», «Интересное», товары и сравнение сохраняют фрагменты URL.

## Проверка и публикация

GitHub Actions собирает и проверяет артефакт в pull request. Браузерный тест открывает тот же артефакт под префиксом `/ARAL-ver-3/`, проверяет маршруты и ресурсы, поиск, фильтры, карточку товара, фасовки, сравнение и региональный фильтр магазинов. Проверенный артефакт публикуется при запуске workflow на `main`.

Для повторения браузерной проверки локально:

```sh
npm install --no-save --no-package-lock playwright@1.57.0
npx playwright install chromium
node scripts/check_release.cjs http://localhost:8000/
```
